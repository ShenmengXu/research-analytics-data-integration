# Research Analytics Data Integration

This repository contains a curated code sample. The workflow integrates bibliographic, citation, open-access, funding, publisher agreement, and article processing charge (APC) data from multiple sources to support research analytics.

## Code Sample

[`research-analytics-data-integration.ipynb`](research-analytics-data-integration.ipynb)

The notebook demonstrates:

- API-based collection and enrichment of scholarly publication data
- integration of data from multiple sources
- identifier normalization, deduplication, and merge validation
- classification and development of analytical variables
- APC estimation and validation
- analysis of federally funded publications and open-access coverage

The notebook is adapted from a larger working project. Credentials, institutional source data, and selected repetitive processing steps are not included. See the notebook for methodological notes, limitations, and contribution details.
